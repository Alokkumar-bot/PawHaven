## Verification & How to Run
1. Open **Visual Studio Code**.
2. Select **File &rarr; Open Folder...** and choose `e:\HTML class\Project`.
3. Right-click **`index.html`** and select **Open with Live Server**.
4. Click the **Faculty Demonstration Access** box to auto-fill credentials.
5. Click **Sign In to Dashboard**.
6. Test the **Logout** button (bottom of sidebar or topbar header): it immediately clears the session and returns to the login screen while safely preserving all animals, fosters, placements, and follow-up data.
